# RAG Document Assistant

A Python project exploring how Large Language Models (LLMs) can answer questions using information retrieved from documents.

## Overview

The goal of this project is to build a document assistant that retrieves relevant information and uses it to generate context-aware answers. The project will explore Retrieval-Augmented Generation (RAG), document processing, and API development.

## Planned Features

- Document loading and text processing
- Splitting documents into searchable chunks
- Embedding generation and semantic search
- Retrieving relevant context for user questions
- Generating answers grounded in retrieved information
- Returning a clear response when the available context is insufficient

## Technology Stack

- Python
- LLMs and Retrieval-Augmented Generation (RAG)
- Vector search
- FastAPI (planned)

## Project Status

In development. Features and implementation details will be updated as the project progresses.
